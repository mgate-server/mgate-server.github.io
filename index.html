# 1. Клонирование репозитория развертывания MGate и переход на последний релиз
git clone https://github.com/mgate-server/mgate.git && cd mgate
git checkout "$(git tag --sort=-v:refname | head -n 1)"

# 2. Автоматическая генерация конфигурации .env и надежных криптосекретов
make init

# 3. Укажите домен и e-mail администратора в .env (MGATE_HOSTNAME, MGATE_ADMIN_EMAIL)
nano .env

# 4. Загрузка образов (ghcr.io/mgate-server/*, публичные, без входа) и запуск стека
docker compose pull && docker compose up -d

# Готово! Веб-интерфейс и панель администратора доступны на https://mail.company.ru/admin
# Установка в кластер Kubernetes через официальный Helm-чарт (из репозитория на последнем релизе)
cd mgate/deploy/helm/mgate
helm install mgate . \
  --namespace mgate --create-namespace \
  --set config.hostname=mail.company.ru \
  --set config.adminEmail=admin@company.ru

Архитектурный контур

Сквозной конвейер обработки и доставки почты

Изолированные службы, проверенные десятилетиями Unix-стандарты и высокоскоростная бизнес-логика на Rust.

01 // INBOUND GATEWAY :25
Postfix MTA
SMTP :25 (входящие) / :465 / :587. Защита от ботов через postscreen.
02 // MILTER & SECURITY
Rspamd + ClamAV
SPF/DKIM/DMARC валидация, байесовский скоринг и потоковый антивирус.
03 // CORE POLICY ENGINE
Rust Backend
Postfix Policy Service (:8081), аутентификация Argon2id, лимиты и квоты.
04 // LMTP STORAGE
Dovecot LMTP
Прием через LMTP, пользовательские Sieve-правила, запись в Maildir.
05 // CLIENT ACCESS :443
Webmail & IMAP
React SPA по HTTPS :443 и защищенный IMAPS :993 для Outlook/Thunderbird.

Преимущества

Почему компании выбирают MGate

Устаревшие почтовые системы требуют непомерных аппаратных ресурсов, подвержены критическим уязвимостям или привязывают вас к зарубежным провайдерам.

Эффективность по ресурсам

В отличие от MS Exchange или Zimbra, требующих десятки гигабайт RAM и тяжелый стек Java/.NET, MGate работает на стандартном Linux сервере от 2 vCPU и 4 GB RAM.

Безопасность OWASP ASVS L2

Хеширование паролей Argon2id, пароли приложений для почтовых клиентов, защита от брутфорса (Leaky Bucket rate limiter) и неизменяемый аудит-лог SHA-256.

Миграция с прежних серверов по IMAP

Встроенный мастер «Импорт и миграция»: фоновый перенос ящиков с Яндекс 360, Google Workspace, Mail.ru и любых IMAP-серверов — пакетно администратором или самим пользователем.
